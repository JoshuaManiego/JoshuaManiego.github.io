Joshua Maniego | Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript, showcasing my background, skills, and school projects as a BSIT student specializing in Cybersecurity at Holy Angel University.

🔗 Live site: https://joshuamaniego.github.io

Pages
Page	Description
index.html	Home page with a short introduction
about.html	Background, goals, and skills I'm developing
projects.html	An interactive, searchable, filterable gallery of my school projects
contact.html	Email, GitHub, phone, and LinkedIn
Features
Responsive layout with a mobile-friendly nav and card grid
Gradient header and glassmorphism-style content cards
Interactive project gallery (projects.html) built with vanilla JavaScript:
Projects are stored as an array of objects, not hardcoded HTML
Live search by title/description
Filter by tag, with the dropdown built dynamically from the data
A results count that updates as you filter
A friendly message instead of a blank page when nothing matches
Tech Stack
HTML5
CSS3 (custom properties, gradients, flexbox, grid, animations)
Vanilla JavaScript ('use strict', array methods, DOM manipulation, event listeners)

Running Locally

No build step required — it's a static site.

Clone the repo:
bash
   git clone https://github.com/JoshuaManiego/JoshuaManiego.github.io.git
Open index.html in your browser, or serve the folder with any static server (e.g. the VS Code "Live Server" extension).
